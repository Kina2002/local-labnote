# 연구노트 · Windows 전자랩노트

기존 책장 디자인을 Windows 데스크톱 창에 담은 전자랩노트입니다. 최신 `Labnote*.exe`를 실행하면 브라우저 주소창 없이 앱 창이 열립니다. 내부 기능은 컴퓨터 안의 임시 `127.0.0.1` 포트에서만 동작하며, 창을 닫으면 함께 종료됩니다. 기록과 첨부파일은 EXE 옆 `data/`에 저장합니다. **실험 항목과 첨부파일은 기본적으로 AI 사용 금지**입니다.

## 실행

Windows에서 최신 `Labnote*.exe` 또는 `start.bat`를 더블클릭하세요. 시작 메뉴에 등록하려면 이 폴더에서 PowerShell로 `powershell -ExecutionPolicy Bypass -File .\install-shortcut.ps1`을 한 번 실행합니다. 그러면 Windows 검색에서 **전자랩노트**로 찾을 수 있습니다. 이 작업 폴더에서는 실행 중에 `web/` 화면 파일이나 `server.py`·`papers.py`가 바뀌면 같은 앱 창에서 새 버전을 자동으로 읽습니다. 입력 중이거나 대화창이 열려 있으면 저장·닫기를 마칠 때까지 화면 갱신을 기다립니다. 소스 파일 없이 EXE만 다른 폴더에 복사한 경우에는 EXE에 포함된 버전이 실행됩니다. 실행기인 `app.py` 자체를 바꿀 때만 EXE를 다시 빌드해야 합니다. 빌드는 `python -m pip install -r requirements.txt pyinstaller` 후 `powershell -ExecutionPolicy Bypass -File .\build-exe.ps1`을 실행합니다. 개발 중에는 `python app.py`로도 실행할 수 있습니다.

기존 웹 화면의 책장, 실험 기록, 그림 편집, 사진 주석, 첨부파일, 그래프, AI 분석, 논문 검색 기능을 그대로 사용합니다. 원본 데이터는 `data/`에 남아 있습니다.

## 사용 순서

왼쪽 **보관한 책·기록**에서 보관한 책을 복원하거나, 선택한 책의 보관 기록을 볼 수 있습니다. 책장 화면에서는 전체 책의 보관 기록을 표시합니다. 보관 기록은 내용·첨부파일을 열람할 수 있고, **이 기록 복원**을 누르면 기존 번호 그대로 목록으로 돌아옵니다.

기록 오른쪽 위 **보관하기**를 누르면 편집 내용을 저장한 뒤 일반 목록에서 보관 목록으로 옮깁니다. **닫기 ×**는 일반 기록에서 책 목차로, 보관 기록에서는 보관 목록으로 돌아갑니다.

1. **내 책장**에서 연구 주제나 논문별로 책을 만듭니다. 책 안의 **새 주제**로 실험을 나눌 수 있습니다. 주제 이름과 실험 번호는 자유롭게 입력하며, `KP-01-01` 같은 번호도 그대로 저장하고 검색할 수 있습니다. 번호를 비우면 기존 자동 번호가 표시됩니다. 번호의 구성 요소를 AI가 알아보는 기능은 아직 추가되지 않았습니다.
   책 첫 화면의 **연구 설계**에는 주제와 관계없이 쓸 수 있는 **연구 배경·문제**, **연구 목적·질문**, **자료조사**, **가설·아이디어**, **평가·판단 기준**의 다섯 기본 양식이 있습니다. 처음에는 각 블록의 제목과 작성 상태만 보입니다. 블록을 펼치면 입력칸 이름과 내용을 쓰는 칸이 보이고, **양식 편집**을 누른 동안에만 입력칸 이름·입력 방식·삭제·추가 기능이 나타납니다. 자료·아이디어·평가 카드는 제목과 내용 요약으로 접혀 있으며 선택한 카드만 펼쳐집니다. 카드는 반복해서 추가할 수 있습니다. 아직 모르는 내용은 비워 두어도 됩니다. 기존에 적은 값과 직접 바꾼 입력칸은 유지되며, 기존 설계 메모는 각 블록의 **기존·추가 자유 메모**에 남습니다. 책 연구 설계는 새 실험에 자동 복사되지 않습니다.
   새 실험을 만들 때 실제 시작 날짜는 비워 둘 수 있습니다. 실험 화면의 **실험 전 설계**에서 이번 실험만의 이유, 예상·가설, 변수·대조군·측정 계획, 실험 전 참고 자료를 적고, 시작한 뒤 제목 아래 실제 시작 날짜·시간을 입력합니다. 책의 설계와 실험의 설계는 각각 독립적으로 저장됩니다.
2. 목적·방법·관찰·결과·내 생각을 쓰고, 마지막 **참고 자료** 칸에 자료명·출처 링크 또는 DOI·참고한 내용을 적습니다. 사진·CSV·XLSX·PDF도 항목별로 첨부할 수 있습니다. 휴대폰 사진은 USB 또는 Android Quick Share로 컴퓨터에 옮긴 후 첨부합니다.
   설계와 실험 기록은 한 페이지에서 이어집니다. 설계는 접고 펼칠 수 있고, 설계 블록은 제목 변경·추가·숨기기·복원·이동·크기 조절이 가능합니다. 책 화면은 창의 너비를 쓰고, 책 설계 블록을 접거나 펼칠 때 블록 사이의 빈 간격을 정리합니다. 책의 연구 설계에는 시간 입력이 없습니다. 실험 전 설계와 진행·결과·고찰 블록에는 각각 실제 날짜와 선택적 시각을 적을 수 있습니다. 저장 시각은 실제 수행 시각으로 자동 입력되지 않습니다.
3. CSV/XLSX 파일 이름을 누르면 표의 숫자 열로 간단한 그래프를 볼 수 있습니다.
4. 책 첫 화면의 **AI 도움 → 설계·실험 분석**에서 책 연구 설계, 실험 전 설계, 실험 기록·파일 중 필요한 항목을 고릅니다. 설계 블록도 기본적으로 🔒 AI 사용 금지이며, 필요한 블록만 🏠 허용한 뒤 선택합니다. **전달 내용 미리보기**로 확인하고 로컬 AI에 질문합니다. 답변은 초안으로 표시되며 설계 블록에 자동으로 쓰지 않습니다. 실험 화면에는 별도의 AI 도움 버튼이 없습니다.
5. 책 첫 화면의 **AI 도움 → 논문 찾기**에서 연구 질문으로 검색어를 제안받거나 직접 입력합니다. 보낼 검색어에 체크하고 확인 창에서 승인하면 Crossref 결과를 가져와 같은 DOI를 합칩니다. 결과의 **참고문헌** 또는 **후속 인용**을 누르면 공개 논문 식별자를 확인한 뒤 Semantic Scholar에서 한 단계씩 찾아봅니다. 원하는 논문은 초안을 편집한 뒤 책의 설계 블록, 실험 전 설계 블록, 실험 기록의 참고 자료 또는 독립 논문 블록 중 저장 위치를 고를 수 있습니다.

실험 기록은 화면 너비에 맞춘 한 페이지에 이어집니다. **블록 추가 → 기록 항목**에서 목적·재료·조건·과정·관찰·결과·내 생각·참고 자료를 각각 새 블록으로 추가할 수 있습니다. 같은 항목도 여러 번 추가할 수 있습니다. **다른 블록**에서는 메모·그림·논문 레퍼런스를 따로 만듭니다. 그림 블록은 스케치·분자구조 편집기와 연결되고, 논문 검색 결과는 독립 레퍼런스 블록으로 저장할 수 있습니다. 참고 자료에 적은 원문 주소와 DOI는 아래의 링크를 눌러 열 수 있습니다. 블록 머리의 ⠿를 끌어 위치를 바꾸고, 오른쪽 아래 ◢를 끌어 너비와 높이를 조정할 수 있습니다. ◢를 두 번 클릭하거나 Enter를 누르면 블록 높이가 내용에 맞춰집니다. 블록 사이의 비어 있는 세로 구간은 기존 기록을 열 때도 접히며, 블록의 가로 위치와 너비는 유지됩니다. ×로 블록을 숨겨도 내용과 첨부파일은 유지되어 **블록 추가 → 복원**으로 다시 볼 수 있습니다. 배치는 기록별로 저장됩니다.

실험 화면의 **실험 삭제**는 본문과 첨부파일을 영구 삭제합니다. **보관하기**는 나중에 복원할 기록에 사용합니다. 주제를 삭제하면 그 안의 기록은 남아 **주제 없음**으로 이동합니다. **책 보관하기**는 책과 그 안의 기록을 일반 목록에서 숨기며, 복원하면 기존 기록과 개별 보관 상태가 그대로 돌아옵니다. **책 삭제**는 책의 주제·활성 및 보관 기록·첨부파일을 모두 영구 삭제합니다. 기본 책 **내 연구**에도 두 기능을 사용할 수 있습니다. 모든 책을 보관하거나 삭제했다면 새 실험을 시작할 때 새 책을 먼저 만듭니다. 삭제할 때는 확인 창에 ‘삭제’를 입력해야 합니다.

로컬 모델을 연결하면 연구 질문에 맞는 영어 검색어를 제안합니다. 모델이 없으면 지원하는 기본 단어로 검색어를 제안하거나, 검색어를 직접 쓸 수 있습니다. 논문 전문을 읽고 싶으면 접근 권한이 있는 PDF를 실험 페이지에 첨부하고 로컬 AI 사용을 허용합니다. Semantic Scholar API 키가 있으면 `LABNOTE_SEMANTIC_SCHOLAR_KEY` 환경 변수로 지정할 수 있습니다.

## 그림과 사진 주석

항목 제목 옆 **＋ 그림 추가**에서 분자구조 또는 스케치를 선택합니다. 그리기 도구는 편집창 안에서만 표시됩니다.

- **분자구조**: 원자 선택, 단일·이중·삼중결합, 오각·육각·벤젠 고리, 원자 이동과 삭제를 지원합니다. 결합은 빈 공간이나 기존 원자에서 드래그하고, 기존 결합을 누르면 선택한 결합 종류로 바뀝니다. 기본 2D 구조식 편집기이며 화학적 타당성 검증, 입체결합, SMILES/MOL 가져오기·내보내기는 지원하지 않습니다.
- **스케치**: 펜, 화살표, 설명, 색상, 이동, 지우개, 실행 취소·다시 실행을 제공합니다.
- **고분자 반복 단위**: **[ ]ₙ 반복단위**를 선택하고 구조를 감싸도록 드래그하면 대괄호와 아래첨자 `n`이 함께 생깁니다. 반복수 칸을 `m`이나 숫자로 바꾼 뒤 그릴 수도 있습니다.
- **올가미와 색상**: 옮길 부분을 올가미로 둘러싼 뒤 선택 안쪽을 드래그하면 원자·결합·표시가 함께 이동합니다. 선택 상태에서 색상을 바꾸면 선택한 부분만 바뀝니다. 원자나 결합 하나는 올가미 도구로 클릭해서 선택할 수 있습니다. 선택을 해제하고 색을 고르면 이후 새로 그리는 원자·결합·고리·표시에 적용됩니다. 선택 테두리는 저장한 그림에 들어가지 않습니다.
- **결합 끝에 고리 연결**: 고리 도구를 선택하고 기존 결합 끝에 마우스를 올리면 연결될 위치가 점선으로 보입니다. 클릭하면 그 원자를 공유하는 고리가 빈 방향으로 붙고, 결합 끝에서 드래그하면 방향을 직접 정할 수 있습니다. 빨간 미리보기는 다른 원자나 화면 경계와 겹쳐서 붙일 수 없는 위치입니다.
- **사진 주석**: 사진을 크게 연 뒤 **화살표·설명 넣기**를 누릅니다. 전·후 부분 사진을 보고 있었다면 해당 영역으로 작업합니다. 원본 파일을 변경하지 않고 주석 사본을 별도 첨부합니다.
- 저장한 그림을 크게 열고 **그림 다시 편집**을 누르면 원자·선·설명을 다시 편집할 수 있습니다. 편집 결과도 새 사본으로 저장하여 이전 그림을 보존합니다. 보관된 실험은 복원 후 편집합니다.
- 그림 아래 **이어서 그리기**로 저장한 구조를 바로 열어 추가할 수 있습니다. **＋ 그림 추가**는 별개의 그림을 만듭니다.
- **배치·크기**를 펼치면 너비(25~100%), 왼쪽·가운데·오른쪽 정렬, 본문 위·아래 위치, 같은 위치에 있는 그림의 순서를 바꿀 수 있습니다. 배치는 새로고침 후에도 유지되고 원본 파일의 크기나 내용은 바꾸지 않습니다.
- **삭제**하면 노트와 AI 분석 대상에서 빠집니다. **삭제한 그림**에서 복원할 수 있도록 실제 파일·편집 데이터는 로컬에 보관합니다. 복원한 그림의 AI 허용은 다시 직접 설정해야 합니다. 원본 사진을 노트에서 삭제해도 해당 사진을 참조하는 주석 사본은 계속 편집할 수 있습니다.
- 분자구조는 기본 **2400 × 1000** 작업지에서 시작합니다. **작업지 넓히기**로 최대 4096 × 4096까지 확장하고, **＋/−**, **전체 보기**, **100%**, **손으로 이동**으로 화면을 조절합니다. Ctrl+휠로도 확대·축소할 수 있습니다. 확장은 실행 취소할 수 있습니다. 노트에 넣을 때는 그림 주변의 빈 여백을 줄인 PNG를 만들고, 다시 편집할 때는 전체 작업지를 복원합니다. 사진 주석은 원래 영역을 유지합니다.
- PNG와 편집 데이터를 이 컴퓨터에 함께 저장합니다. 새 그림과 사본은 항상 **AI 사용 금지**로 시작하고, 원본 사진의 허용 설정을 물려받지 않습니다. 그리기 자체는 AI나 인터넷 연결을 사용하지 않습니다.

## 로컬 AI 연결

LM Studio에서 모델을 내려받고 로컬 서버(`127.0.0.1:1234`)를 켜면 기본 연결을 시도합니다. 사진까지 분석하려면 이미지 입력을 지원하는 모델이 필요합니다. 다른 로컬 모델 서버는 `LABNOTE_LOCAL_MODEL_URL` 환경 변수로 지정할 수 있지만, 앱은 `localhost`/`127.0.0.1` 주소만 허용합니다. 로컬 AI를 설치하지 않아도 기록·첨부·그래프·논문 검색을 사용할 수 있습니다. AI 도움 화면에는 연결 상태가 표시되며, 분석할 항목은 AI 사용을 명시적으로 허용하고 선택해야 합니다.

## 데이터 경계와 현재 한계

- 논문 검색에서 외부로 보내는 내용은 사용자가 확인한 **검색어**(Crossref) 또는 **공개 논문 식별자**(Semantic Scholar)입니다. 로컬 실험 분석 요청에는 허용된 항목만 넣습니다. 잠긴 항목·파일은 분석 요청에서 제외됩니다.
- 새 항목·첨부파일의 기본값은 AI 사용 금지입니다. 사용자가 직접 다른 앱에 데이터를 붙여 넣는 행위나 휴대폰의 사진 자동 백업은 이 앱에서 통제할 수 없습니다.
- `data/` 폴더는 현재 암호화되어 있지 않습니다. 다른 Windows 사용자나 프로그램으로부터 파일을 완전히 격리하는 기능도 아직 없습니다. 민감한 실제 연구 자료를 사용하려면 이 부분을 추가 설계·검증해야 합니다.
- 최근 수정 내역은 확인할 수 있지만, 공식 연구노트 인증이나 법적 증빙을 제공하지 않습니다. AI 설명은 검토용 초안입니다.
- 수정 전 항목 내용은 로컬 데이터베이스에 보관하지만, 현재 화면에는 최근 변경 시각만 표시합니다.
- 그래프는 첫 500행에서 최대 100개 수치를 표시합니다. 전문 통계 분석이나 파일의 모든 행을 그리는 기능은 아직 없습니다.

QR 휴대폰 전송은 후속 기능입니다.

## 논문 기반 예시

로컬 시연에서는 Tzoumani et al. (2023)의 Fig. 8·9를 시료 조건별 **문헌 재구성(LIT)** 기록으로 정리했습니다. 실제 수행일·반복 회차는 원문에서 확인되지 않아 미상으로 표시하고 달력에 가짜 날짜를 넣지 않습니다. 전체 검토는 책 소개에 둡니다. 시연 기록·논문 이미지·개인 데이터와 일회성 데이터 정리 스크립트는 GitHub에 포함하지 않으며, 새로 설치하면 빈 노트로 시작합니다.

실제 실험은 **다음 회차 기록**으로 같은 실험의 새 수행을 시작합니다. 목적·방법·참고 자료만 가져오며 관찰·결과·고찰·첨부파일과 AI 허용 권한은 복사하지 않습니다. 각 회차는 별도 번호와 날짜를 갖고 서로 이동할 수 있습니다. 문헌 조건에서 시작하면 실제 기록의 1회차가 됩니다.

## 개발 검증

Python 테스트는 `python -m unittest test_server test_live_reload`로 실행합니다. Node.js가 설치되어 있다면 `scripts/check_*.mjs` 파일을 각각 `node`로 실행하여 편집기·목차·실험 이동·분자구조 도구의 동작을 검증할 수 있습니다. `data/`와 환경변수 파일은 Git 추적 대상에서 제외합니다.
