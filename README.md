# 로컬 AI 연구노트 · 첫 작동 버전

실험을 기록하고 사진·결과 파일을 붙이며, 그래프를 확인하는 로컬 앱입니다. **실험 항목과 첨부파일은 기본적으로 AI 사용 금지**이며, 사용자가 허용한 것만 컴퓨터에서 실행 중인 AI로 전달합니다.

## 실행

Windows에서 `start.bat`를 실행하세요. Python이 필요합니다. 라이브러리가 없다면 이 폴더에서 `python -m pip install -r requirements.txt`를 한 번 실행합니다. 앱은 `http://127.0.0.1:8765`에서 열리고, 실험 데이터는 이 폴더의 `data/`에 저장됩니다. 다른 컴퓨터에서 접속할 수 없도록 로컬 주소에만 연결합니다.

## 사용 순서

왼쪽 **보관한 기록**에서 선택한 책의 보관 기록을 볼 수 있습니다. 책장 화면에서는 전체 책의 보관 기록을 표시합니다. 보관 기록은 내용·첨부파일을 열람할 수 있고, **이 기록 복원**을 누르면 기존 번호 그대로 목록으로 돌아옵니다.

기록 오른쪽 위 **보관하기**를 누르면 편집 내용을 저장한 뒤 일반 목록에서 보관 목록으로 옮깁니다. **닫기 ×**는 일반 기록에서 책 목차로, 보관 기록에서는 보관 목록으로 돌아갑니다.

1. **내 책장**에서 연구 주제나 논문별로 책을 만듭니다. 책 한 권에 여러 실험 페이지를 넣을 수 있습니다. 책을 고른 뒤 **새 실험**을 누르면 번호가 붙고, 그 책의 타임라인·달력에서 다시 찾을 수 있습니다.
2. 목적·방법·관찰·결과·내 생각을 쓰고, 마지막 **참고 자료** 칸에 자료명·출처 링크 또는 DOI·참고한 내용을 적습니다. 사진·CSV·XLSX·PDF도 항목별로 첨부할 수 있습니다. 휴대폰 사진은 USB 또는 Android Quick Share로 컴퓨터에 옮긴 후 첨부합니다.
3. CSV/XLSX 파일 이름을 누르면 표의 숫자 열로 간단한 그래프를 볼 수 있습니다.
4. AI가 읽어도 되는 항목과 파일만 `🏠 로컬 AI 허용`으로 바꿉니다. `AI 도움`에서 실제 전달 대상을 확인합니다.
5. 논문을 찾을 때는 외부로 보낼 검색어를 직접 입력하고 확인합니다. 검색은 Crossref의 논문 **서지 정보**를 가져옵니다. 논문 전문을 읽고 싶으면 접근 권한이 있는 PDF를 실험 페이지에 첨부하고 로컬 AI 사용을 허용합니다.

## 그림과 사진 주석

항목 제목 옆 **＋ 그림 추가**에서 분자구조 또는 스케치를 선택합니다. 그리기 도구는 편집창 안에서만 표시됩니다.

- **분자구조**: 원자 선택, 단일·이중·삼중결합, 오각·육각·벤젠 고리, 원자 이동과 삭제를 지원합니다. 결합은 빈 공간이나 기존 원자에서 드래그하고, 기존 결합을 누르면 선택한 결합 종류로 바뀝니다. 기본 2D 구조식 편집기이며 화학적 타당성 검증, 입체결합, SMILES/MOL 가져오기·내보내기는 지원하지 않습니다.
- **스케치**: 펜, 화살표, 설명, 색상, 이동, 지우개, 실행 취소·다시 실행을 제공합니다.
- **고분자 반복 단위**: **[ ]ₙ 반복단위**를 선택하고 구조를 감싸도록 드래그하면 대괄호와 아래첨자 `n`이 함께 생깁니다. 반복수 칸을 `m`이나 숫자로 바꾼 뒤 그릴 수도 있습니다.
- **올가미와 색상**: 옮길 부분을 올가미로 둘러싼 뒤 선택 안쪽을 드래그하면 원자·결합·표시가 함께 이동합니다. 선택 상태에서 색상을 바꾸면 선택한 부분만 바뀝니다. 원자나 결합 하나는 올가미 도구로 클릭해서 선택할 수 있습니다. 선택을 해제하고 색을 고르면 이후 새로 그리는 원자·결합·고리·표시에 적용됩니다. 선택 테두리는 저장한 그림에 들어가지 않습니다.
- **결합 끝에 고리 연결**: 고리 도구를 선택하고 기존 결합 끝에 마우스를 올리면 연결될 위치가 점선으로 보입니다. 클릭하면 그 원자를 공유하는 고리가 빈 방향으로 붙고, 결합 끝에서 드래그하면 방향을 직접 정할 수 있습니다. 빨간 미리보기는 다른 원자나 화면 경계와 겹쳐서 붙일 수 없는 위치입니다.
- **사진 주석**: 사진을 크게 연 뒤 **화살표·설명 넣기**를 누릅니다. 전·후 부분 사진을 보고 있었다면 해당 영역으로 작업합니다. 원본 파일을 변경하지 않고 주석 사본을 별도 첨부합니다.
- 저장한 그림을 크게 열고 **그림 다시 편집**을 누르면 원자·선·설명을 다시 편집할 수 있습니다. 편집 결과도 새 사본으로 저장하여 이전 그림을 보존합니다. 보관된 실험은 복원 후 편집합니다.
- 그림 아래 **이어서 그리기**로 저장한 구조를 바로 열어 추가할 수 있습니다. **＋ 그림 추가**는 별개의 그림을 만듭니다.
- **배치·크기**를 펼치면 너비(25~100%), 왼쪽·가운데·오른쪽 정렬, 본문 위·아래 위치, 같은 위치에 있는 그림의 순서를 바꿀 수 있습니다. 배치는 새로고침 후에도 유지되고 원본 파일의 크기나 내용은 바꾸지 않습니다.
- **삭제**하면 노트와 AI 분석 대상에서 빠집니다. **삭제한 그림**에서 복원할 수 있도록 실제 파일·편집 데이터는 로컬에 보관합니다. 복원한 그림의 AI 허용은 다시 직접 설정해야 합니다. 원본 사진을 노트에서 삭제해도 해당 사진을 참조하는 주석 사본은 계속 편집할 수 있습니다.
- 분자구조는 기본 **2400 × 1000** 작업지에서 시작합니다. **작업지 넓히기**로 최대 4096 × 4096까지 확장하고, **＋/−**, **전체 보기**, **100%**, **손으로 이동**으로 화면을 조절합니다. Ctrl+휠로도 확대·축소할 수 있습니다. 확장은 실행 취소할 수 있습니다. 노트에 넣을 때는 그림 주변의 빈 여백을 줄인 PNG를 만들고, 다시 편집할 때는 전체 작업지를 복원합니다. 사진 주석은 원래 영역을 유지합니다.
- PNG와 편집 데이터를 이 컴퓨터에 함께 저장합니다. 새 그림과 사본은 항상 **AI 사용 금지**로 시작하고, 원본 사진의 허용 설정을 물려받지 않습니다. 그리기 자체는 AI나 인터넷 연결을 사용하지 않습니다.

## 로컬 AI 연결

LM Studio에서 모델을 내려받고 로컬 서버(`127.0.0.1:1234`)를 켜면 기본 연결을 시도합니다. 사진까지 분석하려면 이미지 입력을 지원하는 모델이 필요합니다. 다른 로컬 모델 서버는 `LABNOTE_LOCAL_MODEL_URL` 환경 변수로 지정할 수 있지만, 앱은 `localhost`/`127.0.0.1` 주소만 허용합니다. 로컬 AI를 설치하지 않아도 기록·첨부·그래프·논문 검색을 사용할 수 있습니다.

## 데이터 경계와 현재 한계

- 외부로 나가는 앱의 요청은 사용자가 확인한 **논문 검색어**를 Crossref에 보내는 것뿐입니다. 로컬 AI 요청에는 허용된 항목만 넣습니다. 잠긴 항목·파일은 분석 요청에서 제외됩니다.
- 새 항목·첨부파일의 기본값은 AI 사용 금지입니다. 사용자가 직접 다른 앱에 데이터를 붙여 넣는 행위나 휴대폰의 사진 자동 백업은 이 앱에서 통제할 수 없습니다.
- `data/` 폴더는 현재 암호화되어 있지 않습니다. 다른 Windows 사용자나 프로그램으로부터 파일을 완전히 격리하는 기능도 아직 없습니다. 민감한 실제 연구 자료를 사용하려면 이 부분을 추가 설계·검증해야 합니다.
- 최근 수정 내역은 확인할 수 있지만, 공식 연구노트 인증이나 법적 증빙을 제공하지 않습니다. AI 설명은 검토용 초안입니다.
- 수정 전 항목 내용은 로컬 데이터베이스에 보관하지만, 현재 화면에는 최근 변경 시각만 표시합니다.
- 그래프는 첫 500행에서 최대 100개 수치를 표시합니다. 전문 통계 분석이나 파일의 모든 행을 그리는 기능은 아직 없습니다.

QR 휴대폰 전송은 후속 기능입니다.

## 논문 기반 예시

로컬 시연에서는 Tzoumani et al. (2023)의 Fig. 8·9를 시료 조건별 **문헌 재구성(LIT)** 기록으로 정리했습니다. 실제 수행일·반복 회차는 원문에서 확인되지 않아 미상으로 표시하고 달력에 가짜 날짜를 넣지 않습니다. 전체 검토는 책 소개에 둡니다. 시연 기록·논문 이미지·개인 데이터와 일회성 데이터 정리 스크립트는 GitHub에 포함하지 않으며, 새로 설치하면 빈 노트로 시작합니다.

실제 실험은 **다음 회차 기록**으로 같은 실험의 새 수행을 시작합니다. 목적·방법·참고 자료만 가져오며 관찰·결과·고찰·첨부파일과 AI 허용 권한은 복사하지 않습니다. 각 회차는 별도 번호와 날짜를 갖고 서로 이동할 수 있습니다. 문헌 조건에서 시작하면 실제 기록의 1회차가 됩니다.

## 개발 검증

Python 테스트는 `python -m unittest test_server`로 실행합니다. Node.js가 설치되어 있다면 `scripts/check_*.mjs` 파일을 각각 `node`로 실행하여 편집기·목차·실험 이동·분자구조 도구의 동작을 검증할 수 있습니다. `data/`와 환경변수 파일은 Git 추적 대상에서 제외합니다.
